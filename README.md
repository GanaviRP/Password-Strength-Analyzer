Password Strength Analyzer

A Flask-based web application designed to evaluate password security and help users create stronger passwords.

Features
•	Evaluate password strength
•	Display password security feedback
•	Provide suggestions for improving passwords
•	Generate secure passwords
•	Copy generated passwords easily
•	Maintain and view password history

Technologies

HTML,
CSS,
JavaScript,
Python,
Flask,
SQLite

Setup and Usage

1. Open the project folder in VS Code.
2. Set up and activate the Python virtual environment.
3. Start the application using:
bash
python app.py
4.Launch your web browser and visit: 
http://127.0.0.1:5000

Project Purpose:
This project helps users understand password security by analyzing password characteristics and providing useful recommendations for creating stronger passwords.
